WERK WERK

“Build the machine. Press start. Watch it run.”

Sources send out coloured tiles, goals want particular ones. In between you build the machine from belts, splitters, painters and presses. Then you press start and watch, tick by tick, whether everything arrives.

How it works

Build, start, watch

  1. 1

    Read the task

    Sources send out coloured tiles, goals want particular ones – some even in a set order.

  2. 2

    Build the machine

    Lay belts, splitters, painters and presses on the floor. No time pressure: the machine only runs when you press start.

  3. 3

    Press start

    Tick by tick the tiles travel through your machine. If everything arrives, the level is solved – few parts earn three stars.

At a glance

WERK in numbers

  • 12Halls
  • 228Levels
  • 11Parts
  • 0Time pressure
  • Twelve halls, from the first belt to Masterworks with every part on the biggest floor.
  • Eleven parts: belt, bridge, splitter, sorter, painter, press, tunnel, shredder, cutter, sieve and counter.
  • Plus grey scrap that no goal wants, and goals that want their tiles in a set order.
  • No time pressure: build at your own pace; the machine only runs when you press start.
  • Every level has a checked reference machine. Can you match it with as few parts?
