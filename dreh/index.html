DREH DREH

„Ein Wort. Ein Ziel. Die Reihenfolge entscheidet.“

Verwandle ein Startwort Zug um Zug in das Zielwort – mit Karten wie „umdrehen“, „letztes weg“ oder „hinten M“. So wird aus einer LAUS ein WAL und aus einem OTTER eine MOTTE.

DREH in Bewegung

So geht’s

Vom Startwort zum Zielwort

  1. 1

    Ziel ansehen

    Oben steht das Zielwort, darunter dein Startwort. Aus einer LAUS soll ein WAL werden.

  2. 2

    Karten spielen

    Jede Karte verändert das Wort: umdrehen, letztes weg, alle U zu W. Jede Karte nur so oft, wie sie es erlaubt.

  3. 3

    Reihenfolge finden

    Dieselben Karten in anderer Reihenfolge ergeben ein anderes Wort. Mit so wenigen Zügen wie die beste Lösung gibt es drei Sterne.
